# 《Your High-Tech Brain》双语科普网站 — 评审说明

## 一、这是什么

基于神经科学科普海报 **《Your High-Tech Brain — Follow the 8 Sensory Inputs》**（Copyright 2018 www.thehighestofthemountains.com，原海报为 2018 年个人制作的信息图）再设计的**单文件双语科普网站**。

- 中文为主，页面右上角可一键切换中/英文，选择会保存在浏览器本地。
- 无后端、无框架、无构建：一个 HTML 文件 + 原生 JS/CSS，双击即可在浏览器打开。
- 字体走在线字体镜像，首次打开需联网；无网络时自动回退为系统字体，不影响阅读。

1. 保持本文件夹结构不变（HTML 与 `assets/` 同级）。
2. 双击 `高科技大脑科普.html`，建议使用 Chrome / Edge / Safari 最新版。
3. 推荐桌面端 1440px 宽以上查看；已适配 390px 宽手机。

## 四、内容准确性原则（请重点评审）

- **所有数字与引文均逐字转引自原海报**，未自行补造；引文标注海报所印研究出处（如 Wikipedia、BBC、Harvard、Kandel 相关文献等）。
- 站点内设有醒目的**"数据口径说明"框**（中英双语），主动向读者声明海报数字的局限：
  - 全脑突触通行估计约 **100 万亿（10¹⁴）**，海报"65 万亿+"专指大脑皮层；
  - "45,000 台 i7""5 个 A8/单眼 4 个 A8"仅是**按开关数量的量级类比**，突触是可学习的模拟连接，不等于 CPU 算力，不能直接划等号；
  - 脊髓"10 亿神经元"为较早教材（Kalat, 1998）口径，现代细胞计数研究（Herculano-Houzel 等）给出约 2000 万量级，尚无定论；
  - 味蕾"每蕾 5–10 受体"为海报口径，现代研究通常为 50–150 个味觉细胞；
  - 视杆细胞海报标题写 125M、眼球图写 126M，页面两处均保留并说明；
  - DNA"4550 亿 GB/克"为**理论存储密度上限**，不是活体大脑的实际存储量。
- 860 亿神经元、皮层约 150–160 亿、小脑 690 亿与 Azevedo 等（2009）细胞计数研究基本一致。
- 海报本身的非严谨表述（如多巴胺简单归为兴奋性）均保留为"海报原意"，页面用现代教材口径作温和补充，未篡改海报。
