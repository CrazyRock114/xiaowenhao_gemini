# 🌱 小问号百科

面向小学孩子的**问题驱动式互动百科**：每期一个主题，以交互式网页呈现。孩子的开放问题被持续收集、沉淀为知识点，知识点之间建立关联，逐步生长成一张属于孩子自己的知识地图。

```
每期主题（互动探索）→ 孩子冒出新问题 → 提问箱收集 → 家长整理
   → 解答 / 沉淀为知识点 / 催生下一期 → 知识地图生长 → 引出下一期
```

当前已上线 **第 1 期《酿酒和酿醋的秘密》**（发酵 / 微生物 / 家庭实验）。

## 快速开始

```bash
npm install
npm run dev        # 本地开发预览
npm run build      # 内容校验 + 类型检查 + 构建静态站（dist/）
npm run preview    # 预览构建产物
```

## 部署（Vercel）

构建产物是纯静态文件（`dist/`），路由使用 hash 模式（`/#/map`），无需任何服务器重写规则。

**方式一：Vercel 面板（推荐，自动跟随 GitHub）**

1. [vercel.com/new](https://vercel.com/new) 导入 `CrazyRock114/xiaowenhao` 仓库
2. Vercel 会自动识别 Vite：构建命令 `npm run build`，输出目录 `dist`，直接 Deploy
3. 之后每次 push 到 main 自动重新部署

**方式二：命令行**

```bash
npm i -g vercel   # 已安装可跳过
vercel --prod     # 首次会引导创建项目，之后一键部署
```

## 提问箱的两种模式

| 模式 | 说明 |
|---|---|
| 💾 本地保存（默认） | 孩子的提问存在浏览器 localStorage，家长工作台可查看、整理、导出 Markdown |
| ☁️ Supabase 远程备份 | 每条提问额外同步一份到 Supabase（免费层），防止清缓存丢失 |

启用远程备份（可选）：

1. 在 [supabase.com](https://supabase.com) 免费创建项目，SQL Editor 执行：

```sql
create table questions (
  id bigint generated by default as identity primary key,
  text text not null,
  kid text not null,
  source_issue text,
  created_at timestamptz default now()
);

-- 匿名只能插入，不能读取/修改（家长在 Supabase 后台查看）
alter table questions enable row level security;
create policy "anon insert only" on questions
  for insert to anon with check (true);
```

2. 复制 `.env.example` 为 `.env`，填入 `VITE_SUPABASE_URL` 和 `VITE_SUPABASE_ANON_KEY`
3. 在托管平台的环境变量里配置同样的两项

- 下一期制作流程指引

## 内容生产工作流（核心资产）

所有内容都是带 Schema 的结构化 JSON，与渲染完全分离——这是可以长期沉淀、随时迁移的部分。

```
content/
├── issues/001-brewing-vinegar/index.json   # 期内容（块序列 + 测验）
├── knowledge/points.json                   # 知识点库（跨期沉淀，双档解释+关联）
└── schema/                                 # JSON Schema
```

**做新一期的步骤**（家长工作台里也有同款清单）：

1. **选题**：从提问箱挑主题（或直接指定）
2. **写内容**：复制上一期 `index.json` 做模板，按 `issue.schema.json` 的块类型组织：`story` / `qa-card` / `quiz` / `match` / `sort` / `experiment` / `demo` / `vocab` / `open-question` / `related`。让 AI 按模板起草再人工审校是推荐用法
3. **校验**：`npm run validate:content`（Schema、交叉引用、quiz 答案越界、`[[知识点]]` 引用等全查）
4. **预览审校**：`npm run dev`，重点核对科学性、适龄性、安全提示
5. **沉淀知识点**：新概念写入 `points.json`（基础/进阶双档解释 + 关联），登记进期的 `knowledgeIds`
6. **发布**：push 后自动构建上线

> 富文本约定：`**加粗**`；`[[知识点id|显示词]]` 渲染为可点击的词条卡（显示词可省略）。

## 技术栈

Vite 7 · Vue 3 · TypeScript · Vue Router（hash）· Pinia · 原生 CSS 设计令牌 · ajv（内容校验）
